# nav2_action_client.py参数
## 固定常量
这些参数写死在代码顶部，不放进 .yaml 配置文件。因为它们跟着行为设计走，不跟着场地走。
| 参数名 | 默认值 | 含义与设计意图 |
| --- | --- | --- |
| NODE_NAME | 'nav2_action_client' | 该节点在 ROS2 网络中的名字。 |
| NAV_ACTION_NAME | 'navigate_to_pose' | 向 Nav2 发起导航请求时使用的 Action 接口名（由 Nav2 的 bt_navigator 提供）。 |
| NAV_SERVER_WAIT_SEC | 15.0 | 等待 Nav2 服务器就绪的超时时间（秒）。<br>仿真里通常 5 秒就够，但真机上 Nav2 生命周期节点激活慢，改为 15 秒防止误判“服务器不可用”。 |
| FORCE_SUCCESS_DIST | 0.0 (关闭) | “距离极近强制判成功”的阈值。<br>真机默认关闭（0.0）。仿真里如果距离目标只剩 0.3m，可能会触发强制成功，但真机上打滑会导致误判，或者让地图留下“空洞”。 |
| FORCE_SUCCESS_TIME_SEC | 3.0 | 配合上面的强制成功使用。只有导航持续时间超过 3 秒，才允许触发强制成功，防止刚起步就误判。 |
| FORCE_SUCCESS_MIN_MOVE_M | 0.25 | 配合强制成功使用。只有通过 TF 检测到机器人确实移动了超过 0.25 米，才允许触发强制成功。 |
| FEEDBACK_LOG_PERIOD_SEC | 2.0 | 反馈日志节流周期（秒）。<br>导航时反馈是 10~20Hz，逐条打印会把终端刷爆。这里每 2 秒才打印一次剩余距离。 |

## 坐标系配置参数（TF相关）
这两个参数极其关键，用于把地图上的目标点转换成机器人可以理解的位姿。
| 参数名 | 默认值 | 含义 |
| --- | --- | --- |
| self.map_frame | 'map' | 全局固定坐标系。在真机上对应 slam_toolbox 发布的 /map 坐标系。 |
| self.base_frame | 'base_footprint' | 机器人底盘坐标系。真机 TF 链是 map -> odom_combined -> base_footprint -> base_link -> laser |

## 运行状态与线程安全变量
这些变量在 __init__ 中初始化，用于记录当前导航的状态，确保多线程下的逻辑一致。
| 参数名 | 默认值 | 含义 |
| --- | --- | --- |
| self.goal_handle | None | 当前发送给 Nav2 的 NavigateToPose Action 句柄。用来判断是否真的有目标在跑，以及用于取消目标。 |
| self.result_future | None | 等待 Nav2 返回最终结果的 Future 对象。 |
| self._status | 'idle' | 导航状态机的内部状态。只能是 'idle' / 'navigating' / 'success' / 'failed' 四种。 |
| self._status_lock | threading.Lock() | 线程锁。因为 Action 的回调和探索控制器的状态机在不同的线程里跑，必须用锁保护状态读写。 |
| self.nav_start_time | None | 记录本次导航开始的时间戳，用于计算耗时、判断是否软卡死。 |
| self._goal_pose_xy | None | 记录当前目标点的 (x, y) 坐标。 |
| self._first_pose_xy | None | 记录开始导航那一刻，机器人的初始 (x, y) 坐标。用于计算“真的移动过多少距离”。 |
| self._last_feedback_log | None | 上一次打印反馈日志的时间，用于实现日志节流。 |

## feedback_callback中涉及的关键变量
| 变量名 | 含义 |
| --- | --- |
| feedback_msg.feedback.distance_remaining | Nav2 实时反馈的距离目标点还剩多少米。 |
| self.force_success_dist | 如果大于 0，当 distance_remaining 小于该值时，触发强制结束逻辑。 |
| self.force_success_time | 强制结束的时间门槛，防止刚起步就误判。 |
| self.force_success_min_move | 强制结束的位移门槛，防止原地打滑误判。 |
